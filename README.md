# Banking System

A simple banking system project implemented in C++.

## Overview

This project provides a basic implementation of a banking system. It allows users to perform common banking operations such as creating an account, viewing account details, performing transactions, and more. It is designed for educational purposes to demonstrate concepts of C++ programming, including object-oriented programming.

## Features

- Create a new bank account
- View account details
- Deposit money
- Withdraw money
- Transfer funds between accounts
- Delete an account
